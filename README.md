# 汽水音乐自动看广告脚本（优化版）

本项目基于开源项目 [cvabm/qishui](https://github.com/cvabm/qishui) 进行二次开发与逻辑优化。

### 相比原版的改进：
1. **秒退直播间**：识别到屏幕顶部出现「关注」或「更多直播」等特征时，立即触发手机返回键，不用傻等。
2. **精准过滤标题**：修复原版把「再看XX秒继续解锁」倒计时误当成按钮点击导致的无限死循环问题。
3. **防卡死兜底**：当连续多次未能识别到广告目标时，自动执行返回操作，防止停留在未知页面。

---

## 电脑小白手把手使用教程

### 第一步：手机设置（只需设置一次）
1. 打开手机的 **「设置」** -> **「关于手机」**。
2. 连续快速点击 **「版本号」** 7次以上，直到屏幕提示已开启开发者模式。
3. 返回设置页面，找到 **「开发者选项」**。
4. 开启以下开关：
   - **USB 调试**（必须开启）
   - **USB 调试（安全设置）** 或 **允许模拟点击**（小米/vivo等机型必开，否则脚本只能看不能点）。
5. 用数据线把手机连接到电脑，手机弹窗勾选始终允许并确定。

---

### 第二步：安装运行环境
1. 确保电脑已安装 Python 3。
2. 在本项目文件夹上方的地址栏输入 `cmd` 并按回车打开命令行。
3. 输入以下命令安装依赖库并按回车：
   ```bash
   pip install -r requirements.txt
   ```

---

### 第三步：开始使用
1. 手机打开 **汽水音乐**，进入看广告领时长页面。
2. 保持手机屏幕常亮，不要锁屏。
3. 电脑文件夹中双击运行 **`启动.bat`**（或在黑窗口运行 `python qishui_auto.py`）。
4. 控制台显示 `✅ OCR 就绪` 后，脚本开始全自动运行。

---

### 第四步：如何退出
想停止运行时，直接在电脑黑窗口按下键盘快捷键：
```text
Ctrl + C
```
