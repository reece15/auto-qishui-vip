# 汽水音乐自动看广告脚本（优化版）

本项目基于开源项目 [cvabm/qishui](https://github.com/cvabm/qishui) 进行二次开发与逻辑优化。

### 相比原版的改进：
1. **秒退直播间**：识别到屏幕顶部出现「关注」或「更多直播」等特征时，立即触发手机返回键，不用傻等。
2. **精准过滤标题**：修复原版把「再看XX秒继续解锁」倒计时误当成按钮点击导致的无限死循环问题。
3. **防卡死兜底**：当连续多次未能识别到广告目标时，自动执行返回操作，防止停留在未知页面。
4. **精准按钮匹配**：只接受完整目标文字或单个 OCR 错字，避免把“领取新人奖励”误判为“领取奖励”。
5. **倒计时保护**：广告出现“X秒后可领取奖励”时持续等待，不会因连续未匹配而提前返回。

## 电脑小白手把手使用教程

### 第一步：手机设置（只需设置一次）
1. 打开手机的 **「设置」** -> **「关于手机」**。
2. 连续快速点击 **「版本号」** 7次以上，直到屏幕提示已开启开发者模式。
3. 返回设置页面，找到 **「开发者选项」**。
4. 开启以下开关：
   - **USB 调试**（必须开启）
   - **USB 调试（安全设置）** 或 **允许模拟点击**（小米/vivo等机型必开，否则脚本只能看不能点）。
5. 用数据线把手机连接到电脑，手机弹窗勾选始终允许并确定。

---

### 第二步：安装运行环境
1. 确保电脑已安装 Python 3。
2. 在本项目文件夹上方的地址栏输入 `cmd` 并按回车打开命令行。
3. 输入以下命令安装依赖库并按回车：
   ```bash
   pip install -r requirements.txt
   ```
4. `启动.bat` 会优先使用项目目录下的 `.venv\Scripts\python.exe`，不存在时才使用系统 `python`。

---

### 第三步：开始使用
1. 用数据线连接手机，解锁屏幕；手机弹出 USB 调试授权时，勾选“始终允许”并点击“允许”。
2. 手机打开 **汽水音乐**，进入看广告领时长页面。
3. 保持手机屏幕常亮，不要锁屏。
4. 电脑文件夹中双击运行 **`启动.bat`**（或在黑窗口运行 `python qishui_auto.py`）。
5. 控制台显示 `✅ 已连接设备` 和 `✅ OCR 就绪` 后，脚本开始全自动运行。

### ADB 连接说明
脚本通过 Android 官方的 `adb` 截屏和模拟点击。脚本会优先查找项目内的 Platform Tools（如果存在），然后查找系统 PATH / Android SDK：

```text
.tools\platform-tools\adb.exe
```

如需手动检查手机连接状态，在本目录运行：

```powershell
.\.tools\platform-tools\adb.exe devices -l
```

看到 `device` 才表示授权成功；看到 `unauthorized` 时，请解锁手机并允许 USB 调试。

如果项目内没有 `.tools`，可下载 Android 官方 Platform Tools，解压到项目的 `.tools\platform-tools` 目录，或把其中的 `adb.exe` 加入系统 PATH。

如果日志出现 `[WinError 2] 系统找不到指定的文件`，通常就是电脑没有安装 `adb`，或 `adb` 没有加入 PATH。优先使用项目内置的 `.tools` 版本即可，不需要修改系统环境变量。

---

### 第四步：如何退出
想停止运行时，直接在电脑黑窗口按下键盘快捷键：
```text
Ctrl + C
```
